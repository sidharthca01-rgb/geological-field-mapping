# Geological Field Mapping

> A structured portfolio of geological field observations, mapping workflows, and interpreted field evidence.

## About

This repository documents field-based geological work using a reproducible and evidence-led workflow. It is intended for field notebooks, outcrop descriptions, lithological logs, structural measurements, map layouts, and interpretation notes.

The repository is a professional portfolio framework. Replace the example templates with observations collected by you, and clearly identify the location, date, coordinate reference system, instruments, and data source for every field dataset.

## Scope

- Field methods and observation recording
- Lithological and stratigraphic logging
- Structural geology measurements
- Geological map preparation
- Field photographs with captions and scale
- Interpretation and uncertainty documentation

## Data and scientific integrity

- Identify the source, author/organization, date, licence, and version of external data.
- Record coordinate reference systems, units, scale, and methods where relevant.
- Do not invent field observations, analytical results, coordinates, or citations.
- Label synthetic/demo data clearly; never present it as field or laboratory data.
- Include uncertainty, assumptions, and limitations in interpretations.
- Respect site access, safety, privacy, and data-sharing restrictions.
